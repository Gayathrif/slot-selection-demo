# Slot Selection Demo

This project is a simple React-based application that allows users to manage slots for saved badges. It includes features like saving badges to slots, transferring badges between slots, and a user-friendly modal for interaction.

## Features
- Save badges to available slots.
- Transfer badges between slots using a swipeable interface.
- Toggle slot states with a user-friendly switch design.
- Responsive modal for selecting and saving slots.
- Clean, minimalist UI for easy navigation.

---

## Getting Started

Follow these instructions to set up the project locally on your machine.

### Prerequisites
Before running the project, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (version 14 or above)
- [npm](https://www.npmjs.com/) (comes with Node.js) or [yarn](https://yarnpkg.com/)

---

### Installation
1. **Clone the repository**:
   ```bash
   git clone https://github.com/Gayathrif/slot-selection-demo.git
   cd slot-selection-demo

2. **Install dependencies**:


npm install

Run the application:


npm start
This will start the development server and open the app in your default browser at http://localhost:3000.

Usage
Saving Badges
Click on the Saved Badges button to open the modal.
Select a slot from the list.
The slot will be marked as saved.
Transferring Badges
Use the Transfer Badge section to transfer badges between slots.
Swipe left or right to choose the target slot.
Click the Transfer Badge button to complete the transfer.
